FREE PUBLISHING:
1. Create a free GitHub account at github.com.
2. Create a new public repository, e.g. high-sky-music.
3. Upload index.html and logo.png.
4. Repository Settings → Pages → Deploy from branch → main → /(root).
5. GitHub will provide a free website address ending in github.io.

GOOGLE ANALYTICS:
1. In GA4 create a Web stream using the GitHub Pages website URL.
2. Copy the Measurement ID (G-XXXXXXXXXX).
3. Open index.html and uncomment the Google Analytics block near the top.
4. Replace both G-XXXXXXXXXX values with your real Measurement ID.
5. Upload the updated index.html.
